# Alternative C - fabrication drawing package (detailing) - Rev 6a

`C_detail_drawings.dxf` (DXF R2013, `$INSUNITS = 6` metres), generated by `gen/main.py` from the design Rev 6a calculation model (`design/C/calc/model.py`, `bracing.py`, `members_C.csv`) and `bases_C.md` Rev 8. Audit: 0 errors, 0 fixes; 4953 entities (161 real DIMENSION entities). Title strip on every sheet: "Rev 6a superstructure / Rev 8 bases / bracing Rev 5a", date 2026-09-29, revision table (1 first issue, 2 Rev 3, 3 Rev 6a). PNG renders `S00.png` ... `S06.png` (3360 x 2400) are for checking.

## Design state drawn
- Sections: IPE 300 primaries and eave beams (P13 K19-K20 IPE 330), IPE 240 rafters / edge beams / T2 / ST1-ST2, HEA 140 columns and WP1.
- Levels: roof plane TOS(y) = 3.33 + 0.06 (35.87 - y); primary top TOS + 0.03; cap-plate top TOS - 0.27; column top TOS - 0.29; column length TOS - 0.335 (P13 columns TOS - 0.365), cut to the surveyed plate-top level; clear height 3.03 m under the cap-plate nuts, 3.07 m under the eave primary. No precamber.
- Bracing Rev 5a: 13 roof rod panels in 5 strips (RT-N-W, RT-N-E, RT-JOG, RT-W, RT-E), 8 wall bays B1-B7 and B9; rod gussets only at rod corners, combined gussets at the NE corner; fin plates FP1 (2 M20) and FP2 (2 x 2 M20) at the chord splices.
- Bases Rev 8: all 27 type E (4 dia 16 post-installed rebars at 70 x 240, debonded through the 300 mm slab, 250-300 mm into the column head; plates 300x400x20 or key-pair plates per schedule; Key A / Key A + B / inboard key pairs; K21 pier base P with saddle; WP1). No through-bolts, no ceiling access.
- Load basis Rev 3 on S00; north face jog; stair well open to the north face; gutters G-W / G-E, DP1-DP4.
